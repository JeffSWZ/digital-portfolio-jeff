Challenge overview

Challenge overview
Challenge:When developing the LVT Tracker, it was difficult to get my code pushed into production because the initial implementation did not yet meet the required standard of code quality.
Cause:The code worked functionally, but it needed stronger structure, clarity, and maintainability before it could be confidently released.
Resolution:I studied existing patterns, sought feedback regularly, and applied SOLID React principles to improve the quality of the implementation.
Challenge overview
Challenge:When developing the chatbot, the language model would sometimes answer trade-support questions from its own assumptions instead of running a lookup, or call a tool with missing or malformed arguments, producing inconsistent and occasionally misleading responses.
Cause:Tool definitions lacked clear descriptions and strict argument schemas, giving the model weak signal on when and how to use each tool.
Resolution:I tightened each tool's description and argument schema, added backend validation to catch bad or incomplete calls with helpful errors, and scoped every tool to the requesting user's own permissions, so the agent reliably called the right tool with valid inputs.
